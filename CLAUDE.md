# WhisperRadar shared instructions

Read `AGENTS.md` for repository guidance before working here.

For manual script and explainer-plan collaboration, read
`docs/manual-production-workflow.md` and the target production's
`manual_review/handoff.md` before continuing. Keep that handoff current after
meaningful reviews or revisions. The reusable template is
`docs/manual-production-handoff-template.md`.

Respect current renders: do not modify their inputs or stop/restart them without
explicit user authorization. A manual review is not an automated judge pass.
