Video options

Every ImgToVideo option. A blank field inherits: a channel falls back to the global value, the global value to the program default (shown in grey). The render resolution is set on Settings. Changes reach a production when its folder is prepared (the merge stage); a value edited by hand in that production's imgtovideo.json is never overwritten.

Sound effects you can use

Every built-in sound. Press ▶ to hear it (made with ffmpeg the first time). Use a name on a channel's "sound effect" (My Channels) or let the plan name it on a shot. Your own files go in a production's sfx folder (.wav .mp3 .m4a .ogg .flac) and are used by file name. The "Default pop sound" above is what the name pop plays.
