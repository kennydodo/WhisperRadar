Web chat LLMs

Chat websites WhisperRadar drives in a browser window (no API key). z.ai and DeepSeek are built in. To add another, give it a name and its chat address and press Save: a browser window opens - sign in there and close it when you are done. The new LLM then appears in every Writer / Judge dropdown. Find models reads the site's own model menu (after you signed in) and the models then show up in the run forms; Test sends it one word.
