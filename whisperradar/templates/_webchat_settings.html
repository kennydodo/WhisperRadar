Web chat LLMs

Chat websites WhisperRadar drives in a browser window (no API key) - for the script, shotlist, packaging plan, thumbnails and topics. z.ai and DeepSeek are built in; add others here. Each one appears in every Writer / Judge dropdown, with the model, level and switches (DeepThink, Web search...) you define for it.
Selectors are CSS selectors from the site's page (right-click > Inspect). Model / level: "picker button" is the selector of the button that opens the menu (leave empty if the entries are already visible) and "menu text" is what the entry says. Switch: "text on the page" is what the toggle says. First time per site: python -m whisperradar.webchat login <key>. Use Test after saving - the log of the test shows which step failed.
